# AS Shop

اپ مستقل Frappe با مسیر `/as-shop`.

HTML: `as_shop/public/pages/index.html`

ظاهر: `as_shop/public/css/as/`

منطق: `as_shop/public/js/as/`

قالب‌ها و تنظیمات: `as_shop/public/templates/` و `as_shop/public/data/`.

برای ساخت خروجی پس از ویرایش JSON یا قالب: `python3 tools/build.py`.

اپ برای اجرای صفحات به نصب اپ دیگری وابسته نیست. ارتباط با اپ‌های دیگر فقط با URL و API عمومی فهرست نشانی‌ها انجام می‌شود.

## نگهداری و نصب مستقل

نقشه فایل‌ها: `docs/CODE_MAP.fa.md`. ارتباط قالب HTML با JavaScript در `docs/TEMPLATES.fa.md` آمده است.

این اپ را روی سایت مقصد با `bench --site SITE install-app as_shop` نصب کنید؛ پیش از آن پکیج باید با `bench pip install --no-deps -e apps/as_shop` نصب شده و نامش در `sites/apps.txt` ثبت شده باشد. `bench build --app as_shop` و پاک‌کردن کش سایت بعد از تغییر لازم است.

در `site_config.json` همان سایت، `shn_app_urls` را با کلیدهای `panel`، `shahrniaz`، `as` و `shop` و URL کامل هر بخش تنظیم کنید. `shn_directory_url` باید نشانی GET API `shn_portal.api.get_app_directory` روی سایت اصلی باشد. پیش‌فرض محلی در `public/data/integration.json` قابل ویرایش است؛ سپس خروجی را بسازید. URLها عمومی‌اند و نباید رمز یا توکن داشته باشند.

فایل‌های `generated-data.js`، `generated-templates.js`، `integration-defaults.js` و `www/*.html` خروجی ساخت هستند؛ منبع را ویرایش کنید.

موتور اولیه AS در این پکیج مستقل کپی شده است و بعضی توابع صنایع و فروشگاه در هر دو اپ وجود دارند. منابع این اپ از اپ دیگر بارگیری نمی‌شوند.

## بک‌اند مدیریت فروشگاه

این اپ سه DocType مدیریتی دارد:

| DocType | کاربرد |
| --- | --- |
| `AS Shop Product` | کد محصول، عنوان فارسی و انگلیسی، توضیح، قیمت تومان، تصویر اصلی، گالری، دسته، ترتیب نمایش و تیک `Show on Website` |
| `AS Shop Product Image` | ردیف‌های گالری هر محصول با تصویر، کپشن و متن جایگزین |
| `AS Shop Stock Entry` | ورود، خروج یا اصلاح موجودی؛ فقط سند Submit شده موجودی محصول را تغییر می‌دهد |

از مسیر زیر وارد Desk شوید:

```text
http://as-shop.localhost:8001/desk
```

در Workspace به نام `AS Shop` دو میانبر `Products` و `Stock Entries` قرار دارد. برای انتشار محصول، در `AS Shop Product` تیک `Show on Website` را فعال کنید. برای حذف از سایت، تیک را بردارید یا سند را حذف کنید. برای اعلام ناموجودی، `Mark as Out of Stock` را فعال کنید. موجودی واقعی را از طریق `AS Shop Stock Entry` ثبت کنید؛ مقدار `Stock Quantity` محصول خواندنی و محاسبه‌شده است.

قیمت و تصاویر منتشرشده از API زیر خوانده می‌شوند و صفحه `/as-shop#/shop/pets` دیگر کاتالوگ ثابت را منبع اصلی خود نمی‌داند:

```text
GET /api/method/as_shop.api.get_catalog
```

سبد خرید فقط مقدار را در مرورگر نگه می‌دارد و موجودی را رزرو نمی‌کند. API عمومی قیمت، گالری، وضعیت نمایش و موجودی جاری را بازمی‌گرداند؛ ایجاد محصول، تغییر قیمت و ثبت موجودی نیازمند ورود مدیریتی Frappe است.

چهارده طرح فعلی از کاتالوگ قبلی به صورت سند اولیه ساخته شده‌اند، با موجودی صفر. برای قابل‌فروش‌شدن هرکدام یک `Stock In` بسازید و Submit کنید. موجودی اولیه حدس زده نشده است.

## بک‌اند سبد خرید

سبد در `AS Shop Cart` و ردیف‌های آن در `AS Shop Cart Item` ذخیره می‌شود. نشانی مدیریت:

```text
http://as-shop.localhost:8001/desk/as-shop-cart
```

Workspace فروشگاه میانبر `Shopping Carts` دارد. هر مرورگر یک توکن محرمانه دارد؛ روی سرور فقط هش آن ذخیره می‌شود. مهمان به داک‌تایپ سبد دسترسی مستقیم ندارد و فقط با توکن خودش می‌تواند از API همان سبد استفاده کند. توکن را با دیگران به اشتراک نگذارید.

APIها با POST:

```text
/api/method/as_shop.api.get_cart
/api/method/as_shop.api.set_cart_item
/api/method/as_shop.api.clear_cart
```

قیمت و جمع هر سبد از محصول فعلی محاسبه می‌شود. قیمت ارسالی مرورگر پذیرفته نمی‌شود. افزودن یا تغییر تعداد، انتشار محصول و موجودی واقعی را دوباره بررسی می‌کند. حذف محصول پنهان یا ناموجود از سبد امکان‌پذیر است. انتخاب‌های محلی قدیمی در اولین اتصال، در صورت موجودبودن کالا به سبد سرور منتقل می‌شوند. سبد موجودی را رزرو یا کم نمی‌کند و سفارش و پرداخت قطعی ایجاد نمی‌کند.

این تغییر فقط در API، کنترلرهای داک‌تایپ و منطق JavaScript سبد است؛ قالب HTML، فایل‌های CSS و کلاس‌های نمایشی قبلی برای این تغییر دست‌نخورده مانده‌اند.

## قیمت بر اساس تعداد محصول

در فرم AS Shop Product فیلدهای Price (Toman)، Unit Price at Basket Quantity 2، Unit Price at Basket Quantity 3 و Unit Price at Basket Quantity 4+ را تنظیم کنید. همهٔ این مقادیر قیمت هر واحد به تومان هستند. مبنا، مجموع تعداد تمام محصولات داخل سبد است؛ تعداد محصولات مختلف با هم جمع می‌شود. برای نمونه یک عدد A و یک عدد B یعنی اعمال قیمت سطح دو برای هر دو محصول. صفر یا خالی بودن قیمت تعدادی، قیمت اصلی را حفظ می‌کند. سبد و سرور پس از تغییر تعداد، قیمت واحد و مبلغ کل را دوباره محاسبه می‌کنند.

دکمهٔ Set Stock Quantity در فرم محصول، سند Adjustment با اختلاف موجودی می‌سازد. سند را Save و Submit کنید تا موجودی تغییر کند.
